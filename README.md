# BecomeMyScreen

Use an Android tablet as a second display for your Mac, over USB or wirelessly on the same Wi-Fi.
안드로이드 태블릿을 Mac의 두 번째 모니터로 씁니다. USB로, 또는 같은 Wi-Fi에서 무선으로.

**[Download the latest version · 최신 버전 다운로드 (BecomeMyScreen.zip)](https://github.com/ivLis-Studio/BecomeMyScreen-releases/releases/latest/download/BecomeMyScreen.zip)**

- Mac with Apple silicon, macOS 14 or later · Android 8.0 or later tablet with USB debugging
- Signed and notarized by Apple. The tablet app comes inside the Mac app: plug in the cable and the Mac installs and opens it.
- Installed copies update themselves from the releases here.

This repository only holds releases. 이 저장소에는 배포본만 있습니다.
