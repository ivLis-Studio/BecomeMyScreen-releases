# BecomeMyScreen

Use an Android tablet as a second display over USB or Wi-Fi on Windows 11 or an Apple silicon Mac. Connect the tablet by USB once; the computer installs the companion app and pairs it for wireless use.

안드로이드 태블릿을 Windows 또는 Mac의 두 번째 화면으로 씁니다. 처음 한 번 USB로 연결하면 태블릿 앱이 자동으로 설치되고 같은 Wi-Fi에서도 연결할 수 있습니다.

- [Windows installer · Windows 1.1.0 설치](https://github.com/ivLis-Studio/BecomeMyScreen-releases/releases/download/windows-v1.1.0/BecomeMyScreen-Windows-Setup-1.1.0.exe) — Intel/AMD x64 and ARM64 in one download. The installer includes the signed display driver. The app checks and downloads updates from GitHub Releases.
- [Windows portable ZIP and release notes · ZIP 및 릴리즈 안내](https://github.com/ivLis-Studio/BecomeMyScreen-releases/releases/tag/windows-v1.1.0) — if Windows on ARM64 rejects the driver, extract the ZIP and use Start-Mirroring.cmd to mirror your primary screen.
- [Mac download · Mac 다운로드](https://github.com/ivLis-Studio/BecomeMyScreen-releases/releases/latest/download/BecomeMyScreen.zip) — Apple silicon, macOS 14+. Signed and notarized; includes the Android app and Sparkle updates.
